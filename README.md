# Two of Us — Cycle Tracker (v6: edit entries, not just delete)

## What's new

The Timeline tab now has a pencil (✏️) icon next to the × on every entry. Tap it to change that entry's date in place — no need to delete and re-log. Works for bleeding starts, ovulation, mood days, and intimacy.

Tested end-to-end (including the exact edit-a-bleeding-date scenario) with zero errors and confirmed the change saves correctly.
